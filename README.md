# Онлайн Калькулятори та Логічні Завдання

Програма для геометричних розрахунків трикутників та розв'язання логічних задач. Інтерфейс адаптований під комп'ютери (фіксоване бічне меню) та мобільні пристрої (каскадне меню у топі).

---

## Структура проєкту

```text
├── index.html                     # Головний інтерфейс користувача (HTML5)
├── style1.css                     # Стилізація сторінки та адаптивність (CSS3)
└── counter/                       # Папка з логікою JavaScript
    ├── navigation.js              # Контроль відкриття/закриття категорій меню
    ├── resetCurrentBlock.js       # Розумне локальне очищення полів форми
    ├── areaHeron.js               # Формула 1: Площа за 3 сторонами (Герон)
    ├── areaTriangle.js            # Формула 2: Площа за 2 сторонами і кутом
    ├── areaSideHight.js           # Формула 3: Площа за стороною та висотою
    ├── areaThreeCircumradius.js   # Формула 4: Площа за сторонами та радіусом R
    ├── palindrome-number.js       # Завдання 5.1.: Перевірка числа на паліндром
    ├── palindrome-world.js        # Завдання 5.2.: Перевірка слова на паліндром
    ├── anagram.js                 # Завдання 6: Перевірка слів на анаграму
    └── NumberFibonachi.js         # Завдання 7: Чи належить число послідовності Фібоначчі
```

## Особливості інтерфейсу (CSS)

- **Scroll Behavior:** Додано `scroll-behavior: smooth;` для плавного ковзання сторінки до потрібного калькулятора після кліку в меню.
- **Десктопна версія:** Меню `.sidebar-nav` зафіксоване ліворуч (`position: fixed; width: 260px; height: 100vh;`). Контент зміщений на `margin-left: 360px;` для ідеального балансу білого простору.
- **Мобільна версія (@media):** Меню переміщується на самий топ сторінки та розділяється на дві незалежні категорії-кнопки (**Геометрія** та **Логічні завдання**). Контент автоматично розширюється на 100% ширини екрану.

## Порядок ініціалізації DOM та Події (JavaScript)

У проєкті використовується пряме прив'язування подій до елементів керування за допомогою методу `.addEventListener()`.

```javascript
document.getElementById("btnCheckAnagram").addEventListener("click", checkAnagram);
```

### Чому це працює без `DOMContentLoaded` і коли потрібен кінець файлу?

Браузер читає HTML-код сторінки зверху вниз, рядок за рядком:
1. **Якщо скрипт стоїть вгорі (у тегу `<head>`):** Браузер доходить до рядка `document.getElementById`, намагається знайти кнопку, але її ще не існує в пам'яті (бо код самої кнопки розташований нижче в HTML). Функція поверне `null`, і ви отримаєте помилку: `Cannot read properties of null (reading 'addEventListener')`.
2. **Якщо скрипт стоїть у самому кінці (перед `</body>`):** Браузер спочатку успішно створює кнопку на екрані, а вже потім доходить до JavaScript-коду. Кнопка вже існує, тому JavaScript легко знаходить її та вішає «слухача подій».

Саме тому розміщення тегу `<script>` наприкінці HTML-файлу дозволяє уникнути написання додаткових обгорток на кшталт `window.addEventListener("DOMContentLoaded", ...)` і робить код простішим.

## Логіка перевірки паліндромів (Two Pointers)
Для перевірки чисел на паліндром у файлі `palindrome-number.js` реалізовано алгоритм **Двох Покажчиків**, який працює з числом як з масивом елементів `[]`.
### Як це працює:
1. Число перетворюється на масив символів за допомогою `Array.from(String(number))`.
2. Створюються два індекси-покажчики: `firstPointer = 0` (початок) та `lastPointer = length - 1` (кінець).
3. У циклі `while (firstPointer < lastPointer)` вони рухаються назустріч один одному до центру.

```javascript
while (firstPointer < lastPointer) {
    if (digitsArray[firstPointer] !== digitsArray[lastPointer]) {
        return false; // Клаузула захисту: миттєва зупинка при першій помилці
    }
    firstPointer++; // Зсув лівого покажчика вправо
    lastPointer--;  // Зсув правого покажчика вліво
}
return true; // Якщо покажчики зустрілися і збоїв не було — це паліндром
```

### Приклад з масивом `[1, 2, 3, 1, 3, 2, 1]`:

- **Крок 1:** Індекси 0 та 6 (`1 === 1`) ➔ Покажчики звужуються.
- **Крок 2:** Індекси 1 та 5 (`2 === 2`) ➔ Покажчики звужуються.
- **Крок 3:** Індекси 2 та 4 (`3 === 3`) ➔ Покажчики звужуються.
- **Крок 4:** Обидва покажчики зустрічаються на індексі 3 (центральна одиниця `1`). Умова `3 < 3` стає хибною, цикл безпечно завершується і підтверджує паліндром!

## Перевірка належності числу Фібоначчі (Алгоритм у NumberFibonachi.js)
Для перевірки, чи належить введене користувачем число послідовності Фібоначчі (\(0, 1, 1, 2, 3, 5, 8, 13, \dots\)), реалізовано ефективний математичний підхід без генерації всього ряду чисел у циклі.
### Математична основа:
За властивостями чисел Фібоначчі, ціле число \(N\) є числом Фібоначчі тоді і тільки тоді, коли хоча б один із виразів є повним квадратом (квадратом цілого числа):
1. \(5N^2 + 4\)
2. \(5N^2 - 4\)
### Реалізація в коді:

```javascript
/**
 * Допоміжна функція: перевіряє, чи є число повним квадратом
 */
function isPerfectSquare(x) {
    let s = Math.round(Math.sqrt(x));
    return s * s === x;
}

/**
 * Головна логіка перевірки числа Фібоначчі
 */
function isFibonacciNumber(n) {
    if (n < 0) return false; // Послідовність розглядається для невід'ємних чисел
    return isPerfectSquare(5 * n * n + 4) || isPerfectSquare(5 * n * n - 4);
}
```
### Переваги цього підходу:
- **Швидкість роботи \(O(1)\):** Функція виконується миттєво, оскільки замість тривалого перебору елементів у циклі `while` виконується лише два базових математичних обчислення квадратного кореня (`Math.sqrt`).
- **Стійкість до великих чисел:** Дозволяє швидко перевіряти великі значення в межах безпечного діапазону чисел JavaScript (`Number.MAX_SAFE_INTEGER`).



## Розумне очищення полів (Reset)
Кожен блок має кнопку з класом `.btn-reset`. Функція `resetCurrentBlock(event)` використовує метод `.closest('.block')` для виявлення конкретної секції, де працює користувач. Вона очищає інпути та спани результату **лише для поточного калькулятора**, не чіпаючи дані інших формул.
